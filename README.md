# JEAF JUnit Extensions README #

This repository contains the source code of JEAF JUnit Extensions. Project provides a JUnit extensions so that JEAF Services can be run in JUnit environments without having the need to start a web or application server. 

## Links ##
For further information please refer to:

* [JEAF JUnit Extensions](https://anaptecs.atlassian.net/l/c/uBrFBd4r)
* [Maven Repository](https://search.maven.org/artifact/com.anaptecs.jeaf.junit/jeaf-junit-extensions)
* [Javadoc](https://javadoc.io/doc/com.anaptecs.jeaf.junit/jeaf-junit-extensions/latest/index.html)

## How do I get set up? ##

* Create a clone of this repository on your local machine.
* Execute Maven on the top level project `maven clean install`
